# code-dojo

A web app that trains me to write classic front-end interview problems from
memory, one line at a time: a coach sentence for every step, an editor, and
hidden tests.

This repository holds both versions. Each folder is its own Next.js app, with
its own README that says how to run it.

| Folder | Version | State |
| --- | --- | --- |
| [`code-dojo/`](code-dojo) | 1: Arabic interface, line-by-line checker | Finished |
| [`code-dojo-v2/`](code-dojo-v2) | 2: English interface, smart answer checker | In progress, built in phases |
